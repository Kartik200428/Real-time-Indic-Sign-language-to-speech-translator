✦ Features

What makes it work.

⚡

Real-Time Recognition

Processes live webcam frames server-side using MediaPipe Holistic — extracting hand, pose, and facial landmarks simultaneously at up to 30 fps for instant sign detection.

🗣

7 Indian Languages

Recognised sentences are spoken aloud using gTTS, supporting English, Hindi, Bengali, Tamil, Telugu, Marathi, and Gujarati — making ISL accessible across all major Indian languages.

✦

AI Grammar Correction

Groq LLaMA 3.1 reconstructs grammatically correct English from raw ISL gloss words — automatically adding linking verbs, articles, and prepositions before speaking.

🎯

Vote-Based Stability

A majority-vote window across 6 consecutive predictions confirms a word before adding it to the sentence — eliminating flickering and false positives.

🧠

BiLSTM Model

A Bidirectional LSTM processes 30-frame landmark sequences, capturing both forward and backward temporal patterns for robust gesture classification.

🌐

Browser-Based UI

Runs entirely in your browser — no plugins, no installation. The Flask server streams annotated video via MJPEG and serves the full web interface locally.

✦ About

Bridging the silence.

This system captures webcam video server-side, extracts MediaPipe Holistic landmarks across hand joints, body pose, and facial features — feeding 30-frame sequences into a Bidirectional LSTM to recognise 50 ISL word classes in real time.

A vote-based confirmation window stabilises predictions. Sentences are refined by Groq LLM grammar correction and spoken aloud in 7 Indian languages via gTTS.

✦ Pipeline

How it flows.

01

Capture

OpenCV reads webcam frames server-side and flips them for natural mirroring.

02

Landmarks

MediaPipe Holistic extracts 1,692-dimensional feature vectors per frame.

03

BiLSTM

A 30-frame sequence is classified with vote-based confirmation for stability.

04

Speak

Groq LLM refines the sentence. gTTS speaks it in your chosen language.
